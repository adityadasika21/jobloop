# Raw notes — dump anything here

Append-only scratch. Write in your own words, no format required: what you built,
what shipped, a number you measured, what an interviewer asked, a role you liked.
Date each entry so it can be traced later.

**This file is NOT a source of truth.** Nothing here reaches a resume until it
becomes an evidence unit in `master.yaml` (via `jt evidence draft "<the note>"`
then `jt evidence add`, or by hand following the format in that file). That is
deliberate: `jt verify` trusts `master.yaml` absolutely, so a claim has to be
stress-tested with a `probe` before it can be used.

If you are working in Claude web, paste this file alongside `master.yaml` and
`preferences.md` and ask it to write the evidence units.
