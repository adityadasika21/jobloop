# /fit — evaluate a posting without producing documents

`$ARGUMENTS`: URL, pasted JD, or slug. Run `jt intake` (if new) and `jt worksheet` +
`jt screen`, then apply `docs/fit-rubric.md` with `profile/preferences.md`. Write
`jobs/<slug>/fit.md` and present the table, verdict, key strengths, gaps, and the flags
(location, travel, seniority, degree). Do not write a resume or letter; say `/apply <slug>`
does that.
